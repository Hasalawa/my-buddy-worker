# My Buddy Worker Mobile App

A Flutter mobile application for My Buddy Worker project.

## 📱 About

My Buddy Worker is a mobile application built with Flutter that helps users manage their work tasks and buddy connections efficiently.

## 🛠️ Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **Target Platforms**: Android, iOS

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (^3.10.4)
- Dart SDK
- Android Studio / Xcode (for Android/iOS development)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

### Build APK

```bash
flutter build apk --debug
```

### Build iOS

```bash
flutter build ios
```
